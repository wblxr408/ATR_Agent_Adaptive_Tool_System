## 实际验证证据

- 最初两个功能用例在“执行成功”及“创建成功”断言处失败；补实现后通过。
- 新增边界用例发现并修正：未清理过期候选复用、未知费用被当作免费释放、遗漏 Router 费用、单并发候选注册、跨客户端取消、输出入口限额、缺失路径被当作 null 匹配、旧版复检切换活跃指针、部分凭证读取绕过脱敏、环境变更后继续复用。
- 最终命令 `uv run pytest -m 'not sandbox' -q`：**42 passed, 4 deselected**。
- `uv run ruff check atr tests scripts --fix`：修正最后两处导入顺序，无剩余问题。
- `uv run mypy atr`：19个源码文件无类型问题。
- `uv run python scripts/export_schemas.py`：生成7份数据契约及固定五接口定义，数据契约通过 Draft 2020-12 Schema 检查。
- `uv build`：sdist 和 wheel 构建成功。

验证覆盖本次新功能，没有既有代码的回归套件。控制层与适配器用例使用明确的执行/网络替身，验证的是接口、状态和边界处理。tests/test_docker.py 的4个真实隔离用例本次没有执行；也没有调用真实模型、供应商计费端点或运行研究实验。不将这些结果作为实际容器隔离、真实外部服务兼容性或经济收益的证明。
